# Interview Prep AI --- UI/UX Design Audit v2

> Prepared as a senior product/UI designer review. The goal is **not**
> to redesign the product, but to elevate it from a polished portfolio
> project into a production-quality SaaS experience.

------------------------------------------------------------------------

# Overall Goal

The product already has a strong visual identity.

**Keep:** - Editorial serif + sans typography - Cream background - Thick
borders - Minimal aesthetic - Black & neutral design language

**Improve:** - Product messaging - Information hierarchy - UX flow -
Trust - Product storytelling - Motion and polish

# 1. Hero Section

## Current Issues

-   Headline explains *what* the product is but not *why it matters*.
-   "AI Powered Learning" is generic.
-   CTA ("Get Started") lacks intent.
-   Screenshot dominates the hero.

## Goals

The hero should answer:

1.  What is this?
2.  Who is it for?
3.  Why should I trust it?
4.  What happens after clicking?

## Suggested Headlines

-   **Master Technical Interviews, Not Just Memorize Answers**
-   **Prepare Like It's Your Last Interview**
-   **Personalized Interview Preparation Built Around Your Experience**

## Suggested Subtext

Generate role-specific interview questions, understand every concept
with AI explanations, track your progress, and practice until you're
interview-ready.

## Better CTA Examples

-   Start My Interview
-   Generate Questions
-   Create Interview Plan
-   Start Practicing

## Layout Changes

-   Reduce screenshot height by \~20%.
-   Add more breathing room above the preview.

------------------------------------------------------------------------

# 2. Information Hierarchy

## Problem

Every section has equal visual weight.

Result:

The eye doesn't know what deserves attention.

## Recommendation

Introduce visual rhythm.

Instead of:

Feature Feature Feature Feature

Use:

-   Large feature
-   Two small features
-   Screenshot
-   Testimonial
-   Stats
-   Another feature

Think Stripe, Linear, Vercel.

------------------------------------------------------------------------

# 3. Features Section

## Current

Cards describe functionality.

## Missing

Cards don't explain benefits.

Instead of:

> Save Notes

Use:

> Never forget an interview answer again.

Every card should communicate:

Problem → Solution → Benefit

Alternate layouts so the page feels dynamic.

------------------------------------------------------------------------

# 4. Dashboard

## Strengths

-   Beautiful cards
-   Consistent spacing
-   Good typography

## Issues

Too much empty vertical space.

Compress:

Heading → Subtitle → Action Cards → Filters → Sessions

The dashboard should feel productive immediately.

------------------------------------------------------------------------

# 5. Navigation

## Current

Every item has identical weight.

## Recommendation

-   Active page should stand out more.
-   Reduce emphasis on inactive items.
-   Make AI Coach feel premium (badge/icon treatment).

------------------------------------------------------------------------

# 6. Session Cards

Current card is clean but information-light.

Add:

-   Estimated completion
-   Questions remaining
-   Study streak
-   Average score
-   Last opened
-   Completion %

This makes the dashboard feel alive.

------------------------------------------------------------------------

# 7. Question Cards

Current accordion works well.

Improve scanning by color coding.

## Suggested Colors

-   Easy → Green
-   Medium → Orange
-   Hard → Red
-   Technical → Blue
-   Behavioural → Purple
-   System Design → Yellow

------------------------------------------------------------------------

# 8. Progress Dashboard

Progress should become one of the main selling points.

Example metrics:

-   Interview Readiness %
-   Questions Solved
-   Topics Mastered
-   Weak Areas
-   Study Days
-   Daily Streak

------------------------------------------------------------------------

# 9. Empty States

Current experience feels unfinished.

Replace empty lists with:

-   Illustration
-   Friendly copy
-   CTA

Example:

> No interview sessions yet.

> Generate your first interview in under 30 seconds.

\[ Create Session \]

------------------------------------------------------------------------

# 10. Color System

Current palette is excellent.

However almost everything is monochrome.

Introduce subtle accents only where meaningful.

Suggested usage:

-   Green → Success
-   Orange → Learning
-   Blue → Technical
-   Purple → AI
-   Red → Difficult

Maintain roughly:

90% Neutral

10% Accent

------------------------------------------------------------------------

# 11. Iconography

Current icons vary in style.

Standardize around a single icon system.

Recommended:

-   Lucide
-   Heroicons
-   Phosphor

------------------------------------------------------------------------

# 12. Motion

The UI feels static.

Recommended microinteractions:

-   Card hover lift
-   Smooth accordion expansion
-   Fade transitions
-   Button animations
-   Skeleton loading
-   Progress animation

Avoid excessive animations.

------------------------------------------------------------------------

# 13. Trust

Landing page currently provides no social proof.

Add:

-   Questions generated
-   Users
-   Domains covered
-   Average rating

Even beta metrics improve trust.

------------------------------------------------------------------------

# 14. Testimonials

Include 2--3 authentic testimonials.

Focus on outcomes rather than generic praise.

------------------------------------------------------------------------

# 15. Footer

Current footer feels temporary.

Expand it into a proper SaaS footer:

-   Product
-   Roadmap
-   GitHub
-   Documentation
-   Privacy
-   Terms
-   Contact

------------------------------------------------------------------------

# 16. Branding

Current name is descriptive.

Long-term consider a stronger brand identity.

Examples:

-   InterviewOS
-   PrepForge
-   Intervue
-   ReadyHire

(Not urgent.)

------------------------------------------------------------------------

# 17. Dashboard Feature Grid

Currently every card looks identical.

Introduce hierarchy:

-   One primary feature
-   Remaining secondary features

Similar to Notion's dashboard philosophy.

------------------------------------------------------------------------

# 18. Search & Filters

Integrate:

Search

Filters

Sorting

into one toolbar.

Cleaner and more discoverable.

------------------------------------------------------------------------

# 19. Loading Experience

Prefer skeleton loaders instead of spinners.

This makes the application feel much faster.

------------------------------------------------------------------------

# Final Verdict

This project already has a distinct visual identity, which is a major
strength.

The next leap is not visual styling---it's **product design**.

Focus every redesign decision around these questions:

-   What is the user's goal?
-   What action should they take next?
-   Does this reduce friction?
-   Does this build trust?
-   Does this communicate value quickly?

The foundation is already strong. Refining messaging, hierarchy,
interaction design, and storytelling can realistically elevate this from
a solid portfolio project into a SaaS that feels production-ready.
