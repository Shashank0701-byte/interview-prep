# Machine Learning and AI Fundamentals

## Machine Learning Basics

### Types of Machine Learning

#### Supervised Learning
- **Definition**: Learn from labeled training data
- **Goal**: Predict outcomes for new, unseen data
- **Examples**: Classification, Regression
- **Algorithms**: Linear Regression, Logistic Regression, Decision Trees, Random Forest, SVM, Neural Networks

#### Unsupervised Learning
- **Definition**: Learn from unlabeled data to find patterns
- **Goal**: Discover structure and relationships in data
- **Examples**: Clustering, Dimensionality Reduction, Association
- **Algorithms**: K-Means, Hierarchical Clustering, PCA, t-SNE, Apriori

#### Reinforcement Learning
- **Definition**: Learn through interaction with environment
- **Goal**: Maximize cumulative reward through actions
- **Examples**: Game playing, Robotics, Recommendation systems
- **Algorithms**: Q-Learning, Deep Q-Networks, Policy Gradients, Actor-Critic

### Core ML Concepts

#### Features and Labels
- **Features**: Input variables used to make predictions
- **Labels**: Target variables we want to predict
- **Feature Engineering**: Creating new features from existing data
- **Feature Selection**: Choosing most relevant features

#### Training, Validation, and Testing
- **Training Set**: Data used to train the model
- **Validation Set**: Data used to tune hyperparameters
- **Test Set**: Data used to evaluate final model performance
- **Cross-Validation**: Robust method for model evaluation

#### Bias-Variance Tradeoff
- **Bias**: Error from erroneous assumptions in learning algorithm
- **Variance**: Error from sensitivity to small fluctuations in training set
- **High Bias**: Underfitting, model too simple
- **High Variance**: Overfitting, model too complex

## Supervised Learning Algorithms

### Linear Regression
- **Purpose**: Predict continuous values
- **Equation**: y = mx + b (simple), y = β₀ + β₁x₁ + ... + βₙxₙ (multiple)
- **Assumptions**: Linear relationship, independence, homoscedasticity, normality
- **Evaluation**: MSE, RMSE, MAE, R²

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Create and train model
model = LinearRegression()
model.fit(X_train, y_train)

# Make predictions
y_pred = model.predict(X_test)

# Evaluate model
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
```

### Logistic Regression
- **Purpose**: Binary classification
- **Sigmoid Function**: Maps predictions to probability [0,1]
- **Decision Boundary**: Threshold (usually 0.5) for classification
- **Evaluation**: Accuracy, Precision, Recall, F1-Score, ROC-AUC

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix

# Create and train model
model = LogisticRegression()
model.fit(X_train, y_train)

# Make predictions
y_pred = model.predict(X_test)
y_proba = model.predict_proba(X_test)

# Evaluate model
print(classification_report(y_test, y_pred))
print(confusion_matrix(y_test, y_pred))
```

### Decision Trees
- **Purpose**: Classification and regression
- **Structure**: Tree-like model of decisions and their consequences
- **Splitting Criteria**: Gini impurity, Entropy for classification
- **Advantages**: Interpretable, handles non-linear relationships
- **Disadvantages**: Prone to overfitting

### Random Forest
- **Purpose**: Ensemble of decision trees
- **Bagging**: Bootstrap aggregating of multiple trees
- **Feature Randomness**: Random subset of features for each split
- **Advantages**: Reduces overfitting, handles missing values
- **Parameters**: n_estimators, max_depth, min_samples_split

### Support Vector Machines (SVM)
- **Purpose**: Classification and regression
- **Hyperplane**: Decision boundary that maximizes margin
- **Kernel Trick**: Transform data to higher dimensions
- **Kernels**: Linear, Polynomial, RBF, Sigmoid
- **Advantages**: Effective in high dimensions, memory efficient

## Unsupervised Learning Algorithms

### K-Means Clustering
- **Purpose**: Partition data into K clusters
- **Algorithm**: Iterative assignment and update of centroids
- **Distance Metric**: Usually Euclidean distance
- **Challenges**: Choosing K, sensitivity to initialization

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

# Determine optimal K using elbow method
inertias = []
for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(X)
    inertias.append(kmeans.inertia_)

# Fit final model
kmeans = KMeans(n_clusters=3, random_state=42)
cluster_labels = kmeans.fit_predict(X)

# Evaluate clustering
silhouette_avg = silhouette_score(X, cluster_labels)
```

### Hierarchical Clustering
- **Agglomerative**: Bottom-up approach, merge closest clusters
- **Divisive**: Top-down approach, split clusters recursively
- **Linkage Criteria**: Single, Complete, Average, Ward
- **Dendrogram**: Tree diagram showing cluster hierarchy

### Principal Component Analysis (PCA)
- **Purpose**: Dimensionality reduction
- **Goal**: Find directions of maximum variance
- **Applications**: Visualization, noise reduction, feature extraction
- **Explained Variance**: Amount of information retained

```python
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# Apply PCA
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

# Visualize results
plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y)
plt.xlabel('First Principal Component')
plt.ylabel('Second Principal Component')
plt.title('PCA Visualization')
plt.show()

# Check explained variance
print(f"Explained variance ratio: {pca.explained_variance_ratio_}")
```

## Deep Learning Fundamentals

### Neural Network Architecture
- **Input Layer**: Receives raw data
- **Hidden Layers**: Process and transform data
- **Output Layer**: Produces final predictions
- **Activation Functions**: ReLU, Sigmoid, Tanh, Softmax
- **Loss Functions**: MSE, Cross-Entropy, Hinge Loss

### Backpropagation
- **Forward Pass**: Compute predictions and loss
- **Backward Pass**: Compute gradients using chain rule
- **Weight Update**: Adjust weights using optimization algorithm
- **Learning Rate**: Step size for weight updates

### Deep Learning Frameworks
- **TensorFlow**: Google's open-source ML library
- **PyTorch**: Facebook's dynamic computation graph framework
- **Keras**: High-level neural network API
- **Scikit-learn**: Traditional ML algorithms


## Natural Language Processing

### Text Preprocessing
- **Tokenization**: Split text into words or subwords
- **Normalization**: Lowercase, remove punctuation, stemming
- **Stop Word Removal**: Remove common words (the, and, is)
- **Vectorization**: Convert text to numerical representation

### Word Embeddings
- **Word2Vec**: Dense vector representations of words
- **GloVe**: Global vectors for word representation
- **FastText**: Handles subword information
- **Contextual Embeddings**: BERT, GPT, Transformer models

### NLP Tasks
- **Text Classification**: Sentiment analysis, topic classification
- **Named Entity Recognition**: Identify names, places, organizations

## Computer Vision

### Image Processing Basics
- **Pixels**: Basic units of digital images
- **Color Spaces**: RGB, HSV, Grayscale
- **Image Filters**: Gaussian blur, edge detection, sharpening
- **Feature Extraction**: SIFT, SURF, ORB

### Convolutional Neural Networks (CNNs)
- **Convolutional Layers**: Apply filters to detect features
- **Pooling Layers**: Reduce spatial dimensions
- **Fully Connected Layers**: Final classification
- **Transfer Learning**: Use pre-trained models

```python
import tensorflow as tf
from tensorflow.keras import layers, models

# Build CNN
model = models.Sequential([
    layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dense(10, activation='softmax')
])

# Compile and train
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=10, validation_data=(X_val, y_val))
```

## Model Evaluation and Validation

### Classification Metrics
- **Accuracy**: Overall correctness of predictions
- **Precision**: True positives / (True positives + False positives)
- **Recall**: True positives / (True positives + False negatives)
- **F1-Score**: Harmonic mean of precision and recall
- **ROC Curve**: Trade-off between true positive and false positive rates

### Regression Metrics
- **Mean Squared Error (MSE)**: Average of squared differences
- **Root Mean Squared Error (RMSE)**: Square root of MSE
- **Mean Absolute Error (MAE)**: Average of absolute differences
- **R² Score**: Proportion of variance explained

### Cross-Validation Techniques
- **K-Fold CV**: Split data into K folds, use each as validation
- **Stratified K-Fold**: Maintain class distribution in folds
- **Leave-One-Out**: Use one sample as validation, rest for training
- **Time Series CV**: Respect temporal order of data

## Feature Engineering and Selection

### Feature Engineering Techniques
- **Polynomial Features**: Create interaction terms
- **Binning**: Convert continuous to categorical
- **Log Transformations**: Handle skewed distributions
- **One-Hot Encoding**: Convert categorical to numerical
- **Standardization**: Scale features to zero mean, unit variance

### Feature Selection Methods
- **Filter Methods**: Select features based on statistical tests
- **Wrapper Methods**: Use model performance to select features
- **Embedded Methods**: Feature selection as part of model training
- **Dimensionality Reduction**: PCA, LDA, t-SNE

## Ethics and Bias in ML

### Common Bias Issues
- **Data Bias**: Unrepresentative training data
- **Algorithmic Bias**: Biased decision-making
- **Selection Bias**: Non-random sample selection
- **Confirmation Bias**: Reinforcing existing beliefs

### Fairness Metrics
- **Demographic Parity**: Equal outcomes across groups
- **Equal Opportunity**: Equal true positive rates
- **Predictive Parity**: Equal positive predictive values
- **Individual Fairness**: Similar individuals treated similarly

### Ethical Considerations
- **Privacy**: Protect sensitive user data
- **Transparency**: Explain model decisions
- **Accountability**: Responsibility for model outcomes
- **Safety**: Prevent harmful model behavior

## Best Practices

### Data Preparation
- Perform thorough exploratory data analysis
- Handle missing values appropriately
- Split data properly to avoid data leakage
- Document all preprocessing steps

### Model Development
- Start with simple baselines before complex models
- Use cross-validation for robust evaluation
- Track experiments and results systematically
- Consider interpretability alongside performance

### Production Readiness
- Monitor model performance continuously
- Plan for model retraining and updates
- Implement proper error handling and logging
- Consider computational efficiency and latency

### Team Collaboration
- Use version control for code and models
- Document model architecture and decisions
- Share knowledge through code reviews and presentations
- Establish clear ML project workflows
