# Mobile Development Interview Preparation

## iOS Development Fundamentals

### Swift Programming Language
Swift is a powerful, intuitive programming language developed by Apple for iOS, macOS, watchOS, and tvOS app development. It combines the best of modern language features with safety and performance.

#### Core Swift Concepts
- **Optionals**: Handle the absence of values safely
- **Closures**: Self-contained blocks of functionality
- **Generics**: Write flexible and reusable code
- **Protocols**: Define blueprints for methods, properties, and requirements
- **ARC (Automatic Reference Counting)**: Memory management system

#### Swift Code Examples
```swift
// Optional handling
var optionalString: String? = "Hello"
if let unwrappedString = optionalString {
    print(unwrappedString) // "Hello"
}

// Closure example
let greet = { (name: String) in
    return "Hello, \(name)!"
}
print(greet("World")) // "Hello, World!"

// Protocol definition
protocol Drawable {
    func draw()
}

class Circle: Drawable {
    func draw() {
        print("Drawing a circle")
    }
}
```

### UIKit Framework
UIKit provides the necessary infrastructure for building iOS applications. It includes windows, views, controls, and the infrastructure for managing events and user interactions.

#### Key UIKit Components
- **UIViewController**: Manages a screen or portion of screen
- **UIView**: Represents a rectangular area on screen
- **UITableView**: Displays scrollable lists of data
- **UICollectionView**: Flexible grid layouts
- **UINavigationController**: Manages navigation stack

#### MVC Architecture in iOS
Model-View-Controller (MVC) is the fundamental design pattern in iOS development:
- **Model**: Data and business logic
- **View**: UI elements and presentation
- **Controller**: Mediates between Model and View

```swift
class UserViewController: UIViewController {
    @IBOutlet weak var nameLabel: UILabel!
    @IBOutlet weak var emailLabel: UILabel!
    
    var user: User? {
        didSet {
            updateUI()
        }
    }
    
    override func viewDidLoad() {
        super.viewDidLoad()
        updateUI()
    }
    
    private func updateUI() {
        guard let user = user else { return }
        nameLabel.text = user.name
        emailLabel.text = user.email
    }
}
```

### SwiftUI Framework
SwiftUI is Apple's declarative UI framework that allows building user interfaces across all Apple platforms with Swift.

#### SwiftUI Concepts
- **Declarative Syntax**: Describe what you want, not how to get there
- **State Management**: @State, @Binding, @ObservedObject, @StateObject
- **Layout System**: VStack, HStack, ZStack, GeometryReader
- **Navigation**: NavigationView, NavigationLink

```swift
struct ContentView: View {
    @State private var count = 0
    
    var body: some View {
        VStack(spacing: 20) {
            Text("Count: \(count)")
                .font(.largeTitle)
            
            Button("Increment") {
                count += 1
            }
            .padding()
            .background(Color.blue)
            .foregroundColor(.white)
            .cornerRadius(10)
        }
        .padding()
    }
}
```

### Core Data
Core Data is Apple's framework for object graph management and persistence.

#### Core Data Components
- **NSManagedObject**: Base class for managed objects
- **NSManagedObjectContext**: Represents the scratchpad for working with managed objects
- **NSPersistentContainer**: Configures and manages the Core Data stack
- **NSFetchRequest**: Retrieves objects from a persistent store

```swift
class DataManager {
    static let shared = DataManager()
    lazy var persistentContainer: NSPersistentContainer = {
        let container = NSPersistentContainer(name: "DataModel")
        container.loadPersistentStores { _, error in
            if let error = error {
                fatalError("Core Data error: \(error)")
            }
        }
        return container
    }()
    
    var context: NSManagedObjectContext {
        return persistentContainer.viewContext
    }
    
    func save() {
        if context.hasChanges {
            try? context.save()
        }
    }
}
```

## Android Development Fundamentals

### Kotlin Programming Language
Kotlin is Google's preferred language for Android development. It's concise, safe, and fully interoperable with Java.

#### Kotlin Features
- **Null Safety**: Eliminates null pointer exceptions
- **Extension Functions**: Add functionality to existing classes
- **Coroutines**: Simplify asynchronous programming
- **Data Classes**: Concise data holder classes
- **Smart Casts**: Automatic type casting

#### Kotlin Code Examples
```kotlin
// Null safety
val name: String? = null
val length = name?.length ?: 0 // Safe call with Elvis operator

// Extension function
fun String.isPalindrome(): Boolean {
    return this == this.reversed()
}

// Data class
data class User(
    val id: Int,
    val name: String,
    val email: String
)

// Coroutines
suspend fun fetchData(): String {
    delay(1000) // Simulate network delay
    return "Data loaded"
}

// Usage
GlobalScope.launch {
    val result = fetchData()
    println(result)
}
```

Android Architecture Components provide guidance and tools to help build robust, maintainable, and testable apps.

#### Key Components
- **ViewModel**: Stores and manages UI-related data
- **LiveData**: Observable data holder class
- **Room**: Persistence library providing an abstraction layer over SQLite
- **Navigation**: Handle navigation between screens
- **Data Binding**: Bind UI components to data sources

```kotlin
// ViewModel example
class UserViewModel : ViewModel() {
    private val _users = MutableLiveData<List<User>>()
    val users: LiveData<List<User>> = _users
    
    fun loadUsers() {
        viewModelScope.launch {
            _users.value = userRepository.getUsers()
        }
    }

// Room database
@Entity(tableName = "users")
data class User(
    @PrimaryKey val id: Int,
    val name: String,
    val email: String
)

@Dao
interface UserDao {
    @Query("SELECT * FROM users")
    suspend fun getAllUsers(): List<User>
    
    @Insert

    abstract fun userDao(): UserDao
```

### Jetpack Compose
Jetpack Compose is Android's modern toolkit for building native UI with declarative Kotlin code.

#### Compose Concepts
- **Composable Functions**: Build UI by describing functions
- **State Management**: remember, mutableStateOf
- **Layout Components**: Column, Row, Box, LazyColumn
- **Modifiers**: Style and configure components

```kotlin
@Composable
fun CounterScreen() {
    var count by remember { mutableStateOf(0) }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Text(
            text = "Count: $count",
            fontSize = 24.sp,
            fontWeight = FontWeight.Bold
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        Button(
            onClick = { count++ },
            modifier = Modifier.padding(8.dp)
        ) {
            Text("Increment")
        }
    }
}
```

## Cross-Platform Development

### React Native
React Native allows building native mobile apps using React and JavaScript.

#### React Native Concepts
- **Components**: Reusable UI building blocks
- **Props**: Properties passed to components
- **State**: Component's local data
- **Navigation**: React Navigation for screen transitions
- **Native Modules**: Access native device features

```javascript
import React, { useState, useEffect } from 'react';
import { View, Text, Button, StyleSheet, Alert } from 'react-native';

const CounterApp = () => {
    const [count, setCount] = useState(0);
    
    useEffect(() => {
        console.log('Component mounted');
        return () => console.log('Component unmounted');
    }, []);
    
    const incrementCount = () => {
        setCount(prevCount => prevCount + 1);
    };
    
    return (
        <View style={styles.container}>
            <Text style={styles.text}>Count: {count}</Text>
            <Button 
                title="Increment" 
                onPress={incrementCount}
                color="#007AFF"
            />
        </View>
    );
};

const styles = StyleSheet.create({
    container: {
        flex: 1,
        justifyContent: 'center',
        alignItems: 'center',
        backgroundColor: '#F5FCFF',
    },
    text: {
        fontSize: 24,
        fontWeight: 'bold',
        marginBottom: 20,
    },
});
```

### Flutter
Flutter is Google's UI toolkit for building beautiful, natively compiled applications for mobile, web, and desktop from a single codebase.

#### Flutter Concepts
- **Widgets**: Building blocks of Flutter UI
- **Stateful vs Stateless Widgets**: Managing component state
- **Layout Widgets**: Row, Column, Container, Stack
- **Navigation**: Navigator and MaterialPageRoute
- **Packages**: Flutter ecosystem of libraries

```dart
import 'package:flutter/material.dart';

    @override
    _CounterAppState createState() => _CounterAppState();
}

                                padding: EdgeInsets.symmetric(

                    ],
```

## Mobile Development Interview Questions

### iOS Interview Questions

#### Swift Language
**Q: What are optionals in Swift and why are they important?**
A: Optionals represent the possibility that a value might be absent. They're important because they force developers to handle the absence of values explicitly, preventing null pointer exceptions that are common in other languages.

**Q: Explain the difference between let and var in Swift.**
A: `let` creates constants that cannot be changed after assignment, while `var` creates variables that can be modified. Using `let` whenever possible improves code safety and performance.

**Q: What is ARC and how does it work?**
A: ARC (Automatic Reference Counting) is Swift's memory management system. It automatically tracks and manages app memory by counting references to objects and deallocating them when the count reaches zero.

#### UIKit and SwiftUI
**Q: Compare UIKit and SwiftUI. When would you choose one over the other?**
A: UIKit is imperative and mature, with extensive documentation and third-party support. SwiftUI is declarative, modern, and requires less code. Choose SwiftUI for new projects targeting iOS 13+, UIKit for maintaining existing apps or when you need specific UIKit-only features.

**Q: Explain the MVC pattern in iOS development.**
A: MVC separates the app into three components: Model (data and business logic), View (UI elements), and Controller (mediates between Model and View). This separation improves code organization and maintainability.

### Android Interview Questions

#### Kotlin Language
**Q: What are coroutines in Kotlin and why are they useful?**
A: Coroutines are Kotlin's solution to asynchronous programming. They allow writing sequential-looking code that executes asynchronously, making it easier to handle background tasks, network calls, and complex asynchronous operations.

**Q: Explain null safety in Kotlin.**
A: Kotlin's type system distinguishes between nullable and non-nullable types. This prevents null pointer exceptions at compile time by forcing developers to handle null cases explicitly.

#### Android Architecture
**Q: What is MVVM and how does it benefit Android development?**
A: MVVM (Model-View-ViewModel) separates UI (View) from business logic (ViewModel) and data (Model). Benefits include better testability, separation of concerns, and easier maintenance.

**Q: Explain the role of ViewModel in Android Architecture Components.**
A: ViewModel stores and manages UI-related data in a lifecycle-conscious way. It survives configuration changes like screen rotations, preventing data loss and reducing boilerplate code.

### Cross-Platform Interview Questions

**Q: Compare React Native and Flutter.**
A: React Native uses JavaScript and bridges to native components, while Flutter uses Dart and renders its own UI. React Native has better JavaScript ecosystem integration, while Flutter offers better performance and more consistent UI.

**Q: What are the advantages and disadvantages of cross-platform development?**
A: Advantages: Code sharing, faster development, consistent UI across platforms. Disadvantages: Performance overhead, limited access to platform-specific features, larger app size, and dependency on framework updates.
